# Dombives.ai - Shopify & Recharge Demo

Nordkap Coffee — a seeded Shopify dev store + live Recharge sandbox for demoing
AI-driven subscription-commerce workflows. Full presentation here: https://domvibes.ai/recharge

Lern more abbout:
* SHOPIFY AI TOOLKIT: https://shopify.dev/docs/apps/build/ai-toolkit
* REFORGE MCP: https://support.getrecharge.com/hc/en-us/articles/43339934359319-Recharge-Analytics-MCP-Early-Adopter-Program
* Installing Claude Code with Shopify: https://domvibes.vercel.app/shopify-claude-code

**Start with [CLAUDE.md](./CLAUDE.md)** — it's the full project brief (store facts,
data rules, auth, and the Recharge mirror pipeline) and doubles as the context file
if you open this repo in Claude Code.

Authored by Dom Coryell: https://www.linkedin.com/in/domcoryell/


No secrets live in this repo: copy your keys into a local `.env` (gitignored) —
`SHOPIFY_CLIENT_ID`, `SHOPIFY_CLIENT_SECRET`, `RECHARGE_API_KEY`, `KLAVIYO_API_KEY`.
